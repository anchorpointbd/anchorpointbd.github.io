# Launch-1 release checklist

- [ ] Approved content claims are reflected exactly.
- [ ] V12 master remains untouched; web derivative is used consistently.
- [ ] HTML, CSS, and JavaScript validation passes.
- [ ] No broken logo, favicon, social image, email, telephone, WhatsApp, or internal links.
- [ ] Desktop and mobile checks: 320, 375, 390, 768, 900, 1024, and wide desktop.
- [ ] Keyboard navigation, visible focus, mobile menu, form success/error, and reduced-motion checks pass.
- [ ] Form endpoint ownership, spam handling, inbox routing, privacy text, and retention policy are confirmed.
- [ ] Canonical URL, robots, sitemap, structured data, title, description, and social metadata are confirmed.
- [ ] Performance/accessibility checks complete; known exceptions recorded.
- [ ] Deployment and rollback commit recorded.
