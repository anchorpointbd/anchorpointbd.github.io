# Launch-1 architecture

## Public surface

- `index.html`: one conversion-focused home page.
- `404.html`: accessible error page.
- `privacy.html`: contact-data and third-party processing notice.
- `assets/brand/`: approved logo and icon sources.
- `assets/css/site.css`: design tokens and responsive components.
- `assets/js/site.js`: optional progressive enhancement only.

## Data boundary

The website is static. Contact submissions go only to the approved Formspree endpoint. No confidential client, vendor, legal, financial, or project data belongs in the repository or browser code.

## Repository boundary

Scratch and historical pages are not part of Launch-1. They remain in prior history/branches until deliberately archived.
